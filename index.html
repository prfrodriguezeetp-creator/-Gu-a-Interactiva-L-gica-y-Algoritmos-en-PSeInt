📘 Módulo 1 — Validación de Entradas

Validar significa comprobar que los datos que ingresa el usuario sean correctos antes de usarlos. Nunca confíes en lo que escribe el usuario: puede escribir letras donde van números, edades negativas o notas fuera de rango.

La técnica central es el bucle Repetir … Hasta Que: repetimos la lectura del dato mientras sea inválido, y solo salimos cuando cumple la condición.

💡 Regla práctica

Define siempre el rango válido antes de programar. Ejemplo: una nota válida va de 1 a 10, una edad de 1 a 120.

Ejercicio: validar una nota entre 1 y 10

validar_nota.psc 
// Validacion de entrada: nota entre 1 y 10
Algoritmo ValidarNota
	Definir nota Como Entero
	Repetir
		Escribir "Ingrese una nota entre 1 y 10:"
		Leer nota
		Si nota < 1 O nota > 10 Entonces
			Escribir "ERROR: valor fuera de rango. Reintente."
		FinSi
	Hasta Que nota >= 1 Y nota <= 10
	Escribir "Nota aceptada: ", nota
FinAlgoritmo

🔧 Pruébalo: escribí 99 y luego 7. Observa cómo el programa no avanza hasta recibir un dato válido.

📊 Módulo 2 — Vectores (Arreglos)

Un vector es una caja con varios compartimentos numerados que guardan datos del mismo tipo bajo un solo nombre. Se accede a cada posición con un índice: vector[1], vector[2], etc.

En PSeInt se declaran con Dimension. Los índices comienzan en 1. La gran ventaja: recorrer todas las posiciones con un solo bucle Para.

💡 Recuerda

Vector de 5 elementos = 5 variables en una. Ideal para notas, temperaturas, sensores o stock.

Ejercicio: cargar 5 notas, promedio y mayor nota

vectores_notas.psc 
Algoritmo PromedioNotas
	Definir notas, i, suma Como Entero
	Definir mayor, promedio Como Real
	Dimension notas[5]
	suma <- 0
	mayor <- 0
	// Carga del vector con validacion incluida
	Para i <- 1 Hasta 5 Hacer
		Repetir
			Escribir "Ingrese la nota del alumno ", i, " (1 a 10):"
			Leer notas[i]
		Hasta Que notas[i] >= 1 Y notas[i] <= 10
		suma <- suma + notas[i]
		Si notas[i] > mayor Entonces
			mayor <- notas[i]
		FinSi
	FinPara
	promedio <- suma / 5
	Escribir "Promedio del curso: ", promedio
	Escribir "Mayor nota: ", mayor
FinAlgoritmo

🔧 Observa cómo se combinan Vectores + Validación dentro del mismo bucle Para.

🧩 Módulo 3 — Modularización (SubProcesos)

Modularizar es dividir el programa en piezas pequeñas y reutilizables llamadas subprocesos o funciones. Cada una resuelve UNA tarea concreta (validar, calcular, mostrar).

✅ Ventajas

  • El código se lee y corrige más fácil.
  • Si validás en 3 lugares, escribís la función UNA vez y la llamás 3 veces.
  • Retornar devuelve el resultado al programa principal.

Ejercicio: funciones de validación y cálculo

modularizado.psc 
// Funcion que valida y devuelve una nota correcta
SubProceso nota <- LeerNotaValidada(mensaje)
	Definir nota Como Entero
	Repetir
		Escribir "Ingrese nota (1 a 10):"
		Leer nota
	Hasta Que nota >= 1 Y nota <= 10
	Retornar nota
FinSubProceso

// Funcion que calcula el promedio de un vector
SubProceso prom <- CalcularPromedio(vector Por Referencia, n)
	Definir i, suma Como Entero
	suma <- 0
	Para i <- 1 Hasta n Hacer
		suma <- suma + vector[i]
	FinPara
	Retornar suma / n
FinSubProceso

Algoritmo ProgramaPrincipal
	Definir notas, i Como Entero
	Definir promedio Como Real
	Dimension notas[3]
	Para i <- 1 Hasta 3 Hacer
		notas[i] <- LeerNotaValidada()
	FinPara
	prom <- CalcularPromedio(notas, 3)
	Escribir "El promedio es: ", prom
FinAlgoritmo

🏆 DESAFÍO INTEGRADOR

Control de Calidad de Empaquetado

La empresa "PackSafe S.A." controla el peso (en gramos) de 8 cajas de su línea de producción. Una caja es APROBADA si pesa entre 480 g y 520 g inclusive. Te contratan como programador para automatizar el control.

📋 Tu programa debe:

  • 1. Validar cada peso ingresado: rechazar valores menores o iguales a 0 (usá Repetir … Hasta Que en una función llamada LeerPeso()).
  • 2. Guardar los 8 pesos en un vector llamado pesos (usá Dimension pesos[8]).
  • 3. Modularizar: crear una función ContarAprobadas(pesos) que devuelva cuántas cajas cumplen el rango 480–520 g.
  • 4. Mostrar al final: el promedio de peso general, la cantidad de aprobadas y la cantidad de rechazadas.
  • 5. (Bonus) Informar cuál fue la caja más liviana y cuál la más pesada.

📤 Pasos para entregar en Google Classroom:

  • Paso 1: Abrí PSeInt para Android y escribí (o copiá y adaptá) tu solución.
  • Paso 2: Ejecutá el programa y verificá que funcione sin errores, probando también valores inválidos (por ejemplo, un peso negativo: debe pedirlo de nuevo).
  • Paso 3: Guardá tu archivo .psc (Menú → Archivo → Guardar) o tomá una captura de pantalla de la ejecución exitosa.
  • Paso 4: Entrá a Google Classroom → materia Software/Programación → tarea "Desafío Integrador" → adjuntá el archivo y/o la captura → entregá. ✅
